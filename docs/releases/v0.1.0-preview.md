**Status:** Developer-preview release candidate

**Origin:** ViTech Intelligence Solutions

## What this release is

`v0.1.0-preview` is the first public developer preview of ViTech's deterministic authority foundation for governed AI, agents, software, tools, devices, and machines.

The core security proposition is:

> **Model capability may increase without increasing model authority.**

Swoosh separates AI reasoning from permission. Models, classifiers, observability systems, and execution layers may request or inform action, but only the deterministic Swoosh authority path returns authoritative `ALLOW` or `DENY`. In the v0.1 Rust API, successful authorization is represented by an `Allow` receipt; deterministic denials are typed errors (and the reference console surfaces them as `ok: false`). `DENY` is therefore the authority outcome semantics, not a `Decision::Deny` enum variant.

## Verify it

```bash
cargo test --locked --workspace --all-targets
cargo run --locked -p proof-pack --quiet
python scripts/check-rust-provenance.py
python scripts/check-license-coverage.py
```

For protocol verification:

```bash
cd protocol
python -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/python -m unittest discover -s tests -v
```
