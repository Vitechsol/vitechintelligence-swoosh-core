# Technical launch announcement — ViTech Swoosh Core

**ViTech Intelligence Solutions is opening Swoosh Core.**

Swoosh is our deterministic authority layer for governed AI, agents, software, tools, devices, and machines.

The premise is simple:

> **Models may reason. Swoosh decides whether protected action is authorized.**

The open developer preview includes the canonical Rust authority kernel, public protocol contracts, a reproducible adversarial Proof Pack, native/Wasm verification, provenance and SBOM tooling, architecture documentation, and conformance assets.

We are opening the trust foundation so developers can inspect it, challenge it, test it, and build interoperable systems around it.

We are **not** open-sourcing ViTech's private enterprise control plane, protected Intelligence Capsule methods, customer data, production signer custody, or managed enterprise implementation.

The architecture is designed around one invariant:

> **Model capability may increase without increasing model authority.**

Start with the README and Proof Pack. If you find a weakness, ambiguity, or interoperability gap, open an issue or architecture proposal.

**Do not simply trust ViTech. Verify ViTech.**
