# Code of Conduct

## Our commitment

ViTech Intelligence Solutions wants the Swoosh and Halibut open-source communities to be technically rigorous, constructive, and welcoming.

We welcome disagreement about architecture, security assumptions, implementation choices, and design tradeoffs. Challenge the code and the claims directly; treat contributors with respect.

## Expected behavior

Contributors and maintainers should:

- communicate respectfully and professionally;
- critique ideas, code, tests, and evidence rather than people;
- disclose relevant conflicts of interest when reviewing security-sensitive work;
- avoid harassment, discrimination, threats, personal attacks, or deliberate disruption;
- respect privacy, confidentiality, and responsible-security-disclosure boundaries;
- keep security discussions evidence-based and reproducible whenever possible.

## Security-sensitive discussion

Do not publish active secrets, signing material, customer data, exploit details that would create immediate avoidable harm, or protected ViTech commercial content in issues or pull requests.

For vulnerabilities, follow `SECURITY.md`.

## Enforcement

Project maintainers may edit, hide, reject, or remove contributions or participation that materially violate these standards.

Serious or repeated abuse may result in temporary or permanent restriction from project spaces.

## Scope

This Code of Conduct applies to repository issues, pull requests, discussions, reviews, and other official community spaces associated with these projects.
