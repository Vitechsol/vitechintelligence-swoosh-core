# Security Policy

Swoosh is deterministic authority. Generative AI, prompts, classifier scores and observability intelligence are not authorization primitives.

Report suspected vulnerabilities privately to the ViTech repository owners before public disclosure.

A public release requires Rust quality gates, Proof Pack, cargo audit, dependency/license provenance, protocol conformance, native Halibut↔Swoosh conformance, protected main and human review.

> No enterprise extension, AI component, transport adapter or observability component may convert a canonical deterministic DENY into ALLOW.
