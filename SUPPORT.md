# Support

ViTech Swoosh Core is an open-source developer preview maintained by **ViTech Intelligence Solutions**.

Use the appropriate channel so questions and reports can be handled efficiently.

## Bugs

Open a **Bug report** issue with a minimal reproducible example.

## Feature and architecture proposals

Open a **Feature or architecture proposal** issue before implementing substantial changes to:

- deterministic authority semantics;
- signed actions or trust state;
- protocol/schema compatibility;
- revocation, expiry, generation, destination, or effect binding;
- interoperability contracts;
- security boundaries.

Material design changes may require an ADR before implementation.

## Usage questions

Use the **Usage question** issue form for public questions about building, testing, or integrating the open core.

## Security vulnerabilities

Do **not** open a public issue for a vulnerability.

Follow `SECURITY.md`.

## Commercial / enterprise support

This repository intentionally excludes ViTech's private enterprise implementation and protected Intelligence Capsule content. Commercial support, managed deployment, enterprise control-plane functionality, certification, and private integrations are outside the scope of community issues.
